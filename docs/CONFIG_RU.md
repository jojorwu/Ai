# Описание настроек конфигурации

В этом документе подробно описаны все параметры конфигурации проекта, разделенные по категориям.

## HardwareConfig (Настройки оборудования)

Эти параметры управляют тем, как модель использует доступное аппаратное обеспечение.

*   `device`: Устройство для вычислений (`cpu`, `gpu`, `mps`).
*   `strategy`: Стратегия использования памяти (`unified`, `discrete`, `hybrid`).
*   `torch_compile`: Включить `torch.compile` для ускорения модели (рекомендуется для GPU).
*   `num_threads`: Количество потоков для внутриоперационного параллелизма (CPU). 0 — значение по умолчанию.
*   `num_interop_threads`: Количество потоков для меж-операционного параллелизма (CPU). 0 — значение по умолчанию.
*   `enable_mkldnn`: Включить оптимизации oneDNN (MKLDNN) для процессоров Intel.
*   `flush_denormals`: Включить обнуление денормализованных чисел (может ускорить вычисления на CPU).
*   `num_workers`: Количество дочерних процессов для загрузки данных.
*   `pin_memory`: Использовать закрепленную память (pinned memory) для ускорения передачи данных с CPU на GPU.

## ModelConfig (Настройки архитектуры модели)

Определяют структуру трансформера.

*   `vocab_size`: Размер словаря токенизатора.
*   `d_model`: Размерность векторов модели (скрытая размерность).
*   `num_layers`: Количество слоев в модели.
*   `num_heads`: Количество голов в механизме Multi-Head Attention.
*   `num_kv_heads`: Количество голов для Key и Value (используется в Grouped-Query Attention).
*   `d_ff`: Размерность скрытого слоя в Feed-Forward сетях.
*   `max_seq_len`: Максимальная длина последовательности токенов.
*   `dropout_rate`: Вероятность исключения нейронов (dropout) для предотвращения переобучения.
*   `num_experts`: Общее количество "экспертов" в слое Mixture of Experts (MoE).
*   `top_k_experts`: Количество экспертов, выбираемых для каждого токена.
*   `gradient_checkpointing`: Включить чекпоинты градиентов для экономии памяти (за счет небольшого замедления).

## EvolutionConfig (Настройки эволюционного процесса)

Параметры, управляющие обучением популяции агентов.

*   `pretrain_epochs`: Количество эпох начального предварительного обучения базовой модели.
*   `evolution_epochs`: Количество циклов (поколений) эволюции.
*   `num_agents`: Количество агентов в популяции.
*   `num_survivors`: Количество лучших агентов, чья память (LTM) будет объединена с основной моделью.
*   `batch_size`: Размер пакета данных для обучения.
*   `seq_len`: Длина последовательности при обучении.
*   `gradient_accumulation_steps`: Количество шагов для накопления градиентов перед обновлением весов.
*   `validation_split`: Доля данных, выделяемая для валидации.
*   `data_dir`: Директория с обучающими данными.
*   `moe_aux_loss_coeff`: Коэффициент вспомогательной функции потерь для балансировки нагрузки экспертов в MoE.
*   `label_smoothing`: Значение сглаживания меток (0.0 — выключено).

## OptimizerConfig & LTMOptimizerConfig (Настройки оптимизатора)

Параметры алгоритма Adam для обновления весов.

*   `learning_rate`: Скорость обучения.
*   `beta1`, `beta2`: Коэффициенты затухания моментов.
*   `epsilon`: Малое число для предотвращения деления на ноль.
*   `weight_decay`: Коэффициент регуляризации (L2).
*   `max_norm`: Максимальная норма градиентов для их ограничения (clipping).

## DynamicParametersConfig (Настройки генерации текста)

Параметры, используемые при выводе (inference).

*   `temperature`: Температура сэмплирования (выше — более разнообразный текст).
*   `top_k`, `top_p`: Параметры фильтрации наиболее вероятных токенов.
*   `speculative_steps`: Количество шагов спекулятивного декодирования.
*   `context_window_size`: Максимальное количество токенов, удерживаемых в контексте истории.
