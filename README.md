# Трансформер с Нуля на NumPy

Это реализация нейросети-трансформера в стиле GPT (decoder-only) с нуля, используя только библиотеку NumPy. Модель способна обучаться на любых текстовых файлах и генерировать текст на их основе.

## Архитектура

Проект состоит из следующих модульных компонентов, находящихся в папке `nn_components`:
- `Embedding`: Слой для преобразования токенов в векторы.
- `PositionalEncoding`: Добавляет информацию о позиции слов.
- `Attention`: Реализация `ScaledDotProductAttention`.
- `MultiHeadAttention`: Реализация многоголового внимания.
- `LayerNormalization`: Слой нормализации.
- `FeedForward`: Полносвязная сеть.
- `DecoderBlock`: Один блок трансформера, собранный из вышеуказанных компонентов.

Вся модель собирается в файле `model.py`.

## Как запустить

### Шаг 1: Установка зависимостей

Для работы проекта требуется только `numpy`. Установите его с помощью `pip`:

```bash
pip install -r requirements.txt
```

### Шаг 2: Подготовка данных

1.  Найдите один или несколько текстовых файлов в формате `.txt`, на которых вы хотите обучить модель.
2.  Положите эти файлы в папку `data`.

В качестве примера в папке уже лежит файл `sample.txt`. Вы можете добавить свои или заменить его.

### Шаг 3: Обучение модели

Чтобы запустить процесс обучения, выполните скрипт:

```bash
./start/train.sh
```

Скрипт прочитает все `.txt` файлы из папки `data`, обучит на них модель и сохранит обученные веса в файл `model_weights.npz`. Вы можете следить за процессом обучения по уменьшению значения потерь (Loss) каждую эпоху.

### Шаг 4: Генерация текста

После того как модель обучена и веса сохранены, вы можете запустить генерацию текста. Выполните скрипт:

```bash
./start/generate.sh
```

Скрипт загрузит обученную модель и сгенерирует текст на основе стартовой фразы, указанной в `generate.py` (по умолчанию это "Привет"). Вы можете изменить стартовую фразу и параметры генерации (длину, "температуру") прямо в файле `generate.py`.
