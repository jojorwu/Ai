# Инструкция по запуску проекта в Acode на Android

Это руководство поможет вам настроить окружение и запустить скрипты обучения и генерации этого проекта на вашем Android-устройстве с помощью редактора кода Acode и эмулятора терминала Termux.

**Важное замечание:** Обучение нейросетей — очень ресурсоемкая задача. На большинстве мобильных устройств этот процесс будет идти **очень медленно** или может не запуститься вовсе из-за нехватки оперативной памяти. Генерация текста на уже обученной модели требует меньше ресурсов и должна работать лучше.

## Шаг 1: Установка необходимых приложений

1.  **Acode:** Установите редактор кода Acode из [Google Play](https://play.google.com/store/apps/details?id=com.foxdebug.acode).
2.  **Termux:** Установите эмулятор терминала Termux. **Крайне важно** устанавливать его из F-Droid, так как версия в Google Play устарела и больше не поддерживается.
    *   Сначала установите F-Droid с [официального сайта](https.f-droid.org/).
    *   Затем найдите и установите Termux через F-Droid.

## Шаг 2: Настройка окружения в Termux

1.  **Откройте Termux.** При первом запуске он установит базовые пакеты.
2.  **Обновите пакеты:** Выполните команду, чтобы убедиться, что все пакеты последней версии.
    ```bash
    pkg update && pkg upgrade
    ```
3.  **Установите Python и Git:**
    ```bash
    pkg install python git
    ```
4.  **Предоставьте доступ к хранилищу:** Это необходимо, чтобы Termux мог видеть файлы вашего проекта.
    ```bash
    termux-setup-storage
    ```
    Android запросит у вас разрешение. Обязательно предоставьте его. После этого в домашней директории Termux появится папка `storage`, которая является ссылкой на внутреннюю память вашего устройства.

## Шаг 3: Подготовка проекта

1.  **Перейдите в папку с проектом:** В Acode вы можете видеть полный путь к вашему проекту. Обычно файлы находятся в папке `Download`. В Termux вы можете перейти к ней так:
    ```bash
    cd ~/storage/shared/Download/имя_вашей_папки_с_проектом
    ```
    *Замените `имя_вашей_папки_с_проектом` на реальное имя папки.*

2.  **Установите зависимости:** Находясь в папке проекта, выполните команду для установки всех необходимых Python-библиотек.
    ```bash
    pip install -r requirements.txt
    ```
    *Этот процесс может занять значительное время.*

## Шаг 4: Редактирование и запуск

Теперь все готово для работы. Ваш рабочий процесс будет выглядеть так:

1.  **Редактирование в Acode:**
    *   Откройте папку с проектом в Acode.
    *   Редактируйте код, изменяйте параметры в `config.json` (например, `start_text` для генерации).

2.  **Запуск в Termux:**
    *   Переключитесь на приложение Termux. Вы уже должны быть в директории проекта (если нет, вернитесь с помощью команды `cd`).
    *   **Для запуска обучения:**
        ```bash
        python3 train.py
        ```
    *   **Для запуска генерации текста:**
        ```bash
        python3 generate.py
        ```

Результат выполнения скриптов будет выводиться прямо в консоль Termux. Вы можете легко переключаться между Acode для редактирования и Termux для выполнения команд.
